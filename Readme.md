# 📊 Analisador de Desempenho Escolar

Projeto desenvolvido em Python para gerenciar informações acadêmicas e analisar o desempenho de alunos por meio de notas, médias e indicadores de desempenho.

## 🎯 Objetivo

Criar uma aplicação que facilite o acompanhamento do desempenho escolar, organizando informações e transformando notas em dados úteis para análise.

## ⚙️ Funcionalidades

- [x] Cadastro de alunos.
- [x] Registro de notas.
- [x] Cálculo de média individual.
- [ ] Cálculo da média geral da turma.
- [ ] Identificação da maior e menor média.
- [ ] Classificação dos alunos por desempenho.
- [ ] Geração de relatórios acadêmicos.
